# Tank 1990 (Бойове місто)

Аркадна гра **Tank 1990** з одиночним режимом і локальною грою для двох гравців на одному комп'ютері.

## Запуск

1. Встановіть залежності:
   ```bash
   npm install
   ```

2. Запустіть клієнт:
   ```bash
   npm run dev:client
   ```

3. Відкрийте `http://localhost:5173` у браузері.
